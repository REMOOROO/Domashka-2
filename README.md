## 1. О чём работа

Исследуется линейная регрессия и её расширения (полиномиальные признаки, регуляризация, преобразование целевой переменной) на двух типах данных:

1. **Синтетические данные** — три искусственные зависимости с шумом; на них изучаются недообучение, переобучение и роль регуляризации (баллы 3.1–3.4).
2. **Реальные данные** — набор *California Housing*; полный цикл: EDA → предобработка → baseline → улучшение качества → анализ ошибок → выводы (баллы 4.1–4.5).

## 5. Методология

### Часть I. Синтетические данные
- **Функции:** затухающие колебания с трендом (основная), функция Рунге, модуль с высокочастотной «рябью».
- Разбиение train/val = 70/30; модель — `PolynomialFeatures → StandardScaler → LinearRegression / Ridge / Lasso`.
- Подбор степени полинома (1–20) по val-RMSE, кривые «ошибка vs степень».
- Регуляризация при избыточной степени (15): подбор α для Ridge и Lasso, сравнение весов.
- **Артефакты:** веса (`coef_`, `intercept_`), проверка совпадения с аналитическим МНК (`np.linalg.lstsq`), метрики (RMSE, MAE, R²), визуализация подгонок, анализ остатков.

### Часть II. Реальные данные
- **EDA:** распределение таргета (он цензурирован сверху), скошенные признаки с тяжёлыми хвостами, корреляции, карта цен.
- **Разбиение:** train/test = 80/20; выбор моделей по 5-fold CV на train; тест — только для финальной оценки.
- **Предобработка (всё внутри `Pipeline`, без утечки данных):**
  - свой класс `FeatureEngineer`: `RoomsPerPerson`, `BedroomRatio`, `DistNearestCity` (расстояние до 5 крупных городов), повёрнутые координаты, категориальные `GeoCluster` (KMeans по координатам) и `AgeGroup`;
  - свой класс `QuantileClipper` — клиппинг выбросов по квантилям 0.5 % / 99.5 %;
  - `PowerTransformer` для скошенных признаков, `StandardScaler`, `OneHotEncoder`, `ColumnTransformer`.
- **Baseline:** `LinearRegression` на 8 сырых признаках.
- **Улучшение (абляция, каждый шаг добавляет одну идею):** M1 клиппинг + степенное преобразование → M2 новые числовые признаки → M3 категориальные признаки → M4 полиномы 2-й степени + Ridge → M5 логарифм таргета (`TransformedTargetRegressor`) → M6 `GridSearchCV` (степень × α) → M7 Lasso → M8 `SGDRegressor`.
- **Финальная модель** выбирается автоматически по минимальному CV RMSE.
- **Анализ ошибок:** «факт vs прогноз» и остатки (`PredictionErrorDisplay`), MAE по сегментам цены, распределение остатков, карта остатков.

## 7. Основные выводы

- **Синтетика:** линейной зависимости не хватает; качество определяется балансом «смещение–дисперсия». Степень полинома и сила регуляризации — две «ручки» одного и того же регулятора сложности, регуляризация позволяет брать избыточно сложные признаки без катастрофического переобучения.
- **Реальные данные:** вклад каждой идеи оценён в абляции (ΔCV RMSE по шагам). Не каждая идея обязана улучшать метрику — выбор делается по кросс-валидации, а не «по ощущению».
- **Адекватность метрик:** RMSE/MAE интерпретируются в долларах, R² — доля объяснённой дисперсии; метрики нужно читать с учётом **цензурирования таргета** сверху (дорогие блоки обрезаны).
- **Ошибки неоднородны:** MAE зависит от сегмента цены, на карте остатков остаются географические области систематической ошибки — допущения классической линейной регрессии выполняются лишь приближённо.
- **Что дальше:** градиентный бустинг/деревья, сплайны по координатам, цензурированная регрессия для обрезанных значений таргета.
